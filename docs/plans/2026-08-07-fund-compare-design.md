# 基金对比功能设计文档

## 目标
让用户可以在系统中选择多只基金，并在同一页面并排查看关键指标和净值走势对比。

## 用户流程
1. 用户在 **基金总览** 页面通过卡片上的复选框选择 2~5 只基金。
2. 选中后页面顶部出现“对比”按钮，点击跳转到 `/compare?ids=id1,id2,id3`。
3. 对比页加载选中基金数据，展示：
   - 并排指标卡片（基金名称、代码、类别、最新净值、日涨幅、基金经理等）。
   - 同一张折线图展示各基金近 N 日净值走势。
4. 用户可以移除某只基金或重新选择。

## 前端设计

### 路由
- `/compare?ids=...`：对比页，接收逗号分隔的基金 ID。

### 组件
- `CompareView.vue`
  - 顶部：标题、返回按钮、基金选择器（搜索添加基金）。
  - 中部：`CompareMetrics.vue` 展示并排指标表格/卡片。
  - 下部：`CompareChart.vue` 使用 `vue-chartjs` 绘制多条净值曲线。
- `OverviewView.vue` 修改：
  - 每张基金卡片添加复选框。
  - 顶部工具栏增加“对比 N 只基金”按钮。

### 状态管理
- 不引入新 Pinia store，仅通过 URL query params 传递选中的基金 ID。
- 对比页从 URL 读取 `ids`，调用接口获取数据。

### 交互限制
- 最多允许选择 5 只基金，超出时提示用户。
- 当只选中 1 只或 0 只时，对比按钮禁用。

## 后端设计

### 新增接口
- `GET /api/funds/compare?ids=id1,id2,id3`
  - 接收逗号分隔的基金 UUID。
  - 最多返回 5 只基金。
  - 返回每只基金的最新详情 + 最近 30 条净值记录，用于前端图表。

### 响应结构
```json
{
  "funds": [
    {
      "id": "uuid",
      "name": "基金 A",
      "code": "000001",
      "category": "混合型",
      "nav": 1.2345,
      "daily_return": 0.0123,
      "manager": "张三",
      "nav_history": [
        {"date": "2026-08-01", "nav": 1.2000},
        {"date": "2026-08-02", "nav": 1.2100}
      ]
    }
  ]
}
```

### 数据查询
- 复用 `funds.py` 中已有的最新表现子查询。
- `nav_history` 取每只基金主代码最近 90 条按日期排序的业绩记录。

## 错误处理
- `ids` 为空或格式错误：返回 `400 Bad Request`。
- 超过 5 只：返回 `400 Bad Request`。
- 某只基金不存在：跳过该 ID 并返回其余数据（前端展示缺失提示）。

## 样式
- 使用现有 Tailwind 主题色。
- 指标表格使用卡片式布局，移动端横向滚动。
- 图表区域高度固定 360px，带图例。

## 测试要点
- 后端接口参数校验（空、非法 UUID、超过 5 只）。
- 前端最多选择 5 只的交互限制。
- 图表在选中 2 只以上时正确显示多条线。

## 依赖
- 前端：`vue-chartjs`、`chart.js`（已安装）。
- 后端：现有 SQLAlchemy + FastAPI 即可，无需新依赖。

## 后续扩展
- 支持对比不同时间维度（近 1 月 / 近 3 月 / 近 1 年）。
- 支持导出对比报告为 PDF 或图片。
